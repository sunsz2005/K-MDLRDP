This directory contains the reconstructed three-, four-, and five-layer PPI
instances used by the biological experiments, plus `sample-2layer`, a small
smoke-test instance maintained by this project.

The synthetic benchmark suite used in the manuscript follows the instance
format of the reference `k-MLRDP` release and is not redistributed here.
Supply its `Instances` directory to `python/run_experiments.py` when
reproducing the synthetic experiments. All published synthetic run ledgers,
protocols, label vectors, summaries, and validation reports are included
under `Results/formal` and `formal_experiments`.
